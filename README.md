# Zika Virus Transmission Model in R

This project implements a deterministic compartmental model of Zika virus transmission between humans and mosquitoes using differential equations.

## Model Features
- Human compartments: Susceptible, Infectious, Recovered
- Mosquito compartments: Susceptible, Exposed, Infectious
- Simulation over short-term and long-term periods

## Tools
- R
- deSolve
- tidyverse
- ggplot2

## Purpose
To demonstrate infectious disease modelling and simulation using R.
